# Algoritmos e Pensamento Computacional

Códigos desenvolvidos nas experiências práticas da disciplina de Algoritmos e Pensamento Computacional (curso de Engenharia de Software).

## Atividades

| Pasta | Tema | Conteúdo |
|---|---|---|
| `atividade-01-variacao-precos` | Variação de preços da cesta básica | Pseudocódigo (Portugol), variáveis, fórmula de variação percentual, decisões e fluxograma |
| `atividade-02-cardapio-digital` | Cardápio digital | Programa em C com menu interativo (`do-while`), `switch`, `if / else if`, validação de entradas e soma do pedido |
| `atividade-03-pedagio` | Controle de pedágio | Programa em C com vetor e matriz, laços `for`, dia de pico destacado no terminal |
| `atividade-04-bubble-sort` | Audiência de músicas | Programa em C com Bubble Sort, ordem crescente e decrescente |

## Como compilar e executar (programas em C)

Com o `gcc` instalado, dentro da pasta da atividade:

```
gcc arquivo.c -o programa
./programa
```

No Windows, o executável é `programa.exe`.

Observação: o programa do pedágio usa códigos de cor ANSI para destacar o dia de pico. Em alguns terminais ou compiladores online a cor pode não aparecer, mas o restante funciona normalmente.

## Tecnologias

- Linguagem C
- Pseudocódigo (Portugol)
